## 四、关键公式速查

### 1. 折扣回报 (Discounted Return)

整条轨迹的回报（用于 Trajectory-Based PG）：

```
Q(s_t, a_t) = sum_{t'=0}^{T} gamma^{t'} * r_{t'}
```

### 2. Reward-To-Go

每个时间步只算未来的回报：

```
Q(s_t, a_t) = sum_{t'=t}^{T} gamma^{(t'-t)} * r_{t'}
```

递推形式（从后往前算）：

```
Q_t = r_t + gamma * Q_{t+1}
```

### 3. Advantage (有基线)

```
A(s_t, a_t) = Q(s_t, a_t) - V(s_t)
```

### 4. GAE (广义优势估计)

```
delta_t = r_t + gamma * V(s_{t+1}) - V(s_t)
A_t^{GAE} = delta_t + (gamma * lambda) * A_{t+1}^{GAE}
```

边界处理：如果 `terminal[t] == 1`，则 `V(s_{t+1}) = 0`。

### 5. 策略梯度损失

```
loss = -E[ log pi(a|s) * A(s,a) ]
```

PyTorch 实现：

```python
loss = -(log_prob * advantages).mean()
```

## 六、调试建议

1. **先验证 Q 值计算:** 在 CartPole 上运行，打印 Q 值，检查是否随时间递减（reward-to-go 应该从大到小）
2. **检查 advantage 分布:** 打印 `advantages.mean()` 和 `advantages.std()`，确保归一化后接近 0 和 1
3. **梯度检查:** 确保 `loss.backward()` 之后 `actor` 的参数有梯度
4. **基线效果:** 对比 `use_baseline=True/False` 的训练曲线，基线应该降低方差
5. **GAE 检查:** `gae_lambda=1.0` 应该等价于有基线无 GAE 的情况；`gae_lambda=0.0` 等价于单步 TD
